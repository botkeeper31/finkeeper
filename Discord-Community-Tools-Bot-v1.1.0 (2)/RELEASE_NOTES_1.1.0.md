# Simple Community Bot v1.1.0

This first release contains only:

- Two configurable verification groups with optional pending roles
- USD and GBP tribute logging and member totals
- Private Verification, Support, and Other tickets
- Moderator-only ticket transcripts and close/delete controls
- Independent sticky notes in multiple channels
- Small, Medium, Large, Group Two, custom, and reaction-signup wheels

It can be installed in multiple Discord servers. Commands register globally, while every server's settings and records remain separated by Discord server ID in one SQLite database stored on a Railway volume.
